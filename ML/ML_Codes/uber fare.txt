## 7. Algorithms

Q34. What is Linear Regression?

Linear Regression is a supervised learning algorithm that predicts continuous values using a linear relationship between variables.

Formula:

\\[ Y=mX+c \\]

Where:

- Y = Predicted fare
- X = Distance
- m = Slope
- c = Intercept

Q35. What is Random Forest Regression?

It is an ensemble learning algorithm that combines multiple decision trees to predict continuous values.

Q36. What is `n_estimators=100`?

It means the Random Forest model uses 100 decision trees.

Q37. What is the difference between Linear Regression and Random Forest?

| Linear Regression              | Random Forest                |
| ------------------------------ | ---------------------------- |
| Uses a linear relationship     | Uses multiple decision trees |
| Simple model                   | Ensemble model               |
| Easy to interpret              | More complex                 |
| Works well for linear patterns | Can learn complex patterns   |

## 8. Model evaluation

Q38. What is MAE?

Mean Absolute Error measures the average absolute difference between actual and predicted values.

Q39. What is MSE?

Mean Squared Error calculates the average of squared prediction errors.

Q40. What is RMSE?

Root Mean Squared Error is the square root of MSE. Lower RMSE generally indicates better predictions.

Q41. What is R-squared?

R-squared measures how well the model explains the variation in the target variable.

A value closer to 1 generally indicates a better fit.

Q42. What is MAPE?

Mean Absolute Percentage Error measures prediction error as a percentage.
