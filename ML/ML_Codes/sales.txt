# 2. Elbow Method Graph

[NBA Play Style Evolution](https://images.openai.com/static-rsc-4/YElnfMOsfcMq9zb347BbdNqzrFD60HbuAvKzLFH5u_v8To2y8CB0qSOYOLdU1UacCIivcKcS8H7YwjZWGNVQrLUhnDaS5Mu7FBjNNYXfIKUlfCZgAJQc8LtV2FHbcfWXMMXzKdwG2yQnBgRXgoR_inEG8o83xVaMMUuVKJWCVH0?purpose=inline)

What is this graph?

The Elbow Method is used to find the optimal number of clusters (K) in K-Means clustering.

Understanding your graph:

- X-axis: Number of clusters (1 to 10).
- Y-axis: Inertia.
- The line decreases as the number of clusters increases.
- Initially, inertia decreases rapidly.
- After approximately K = 3, the decrease becomes slower.

Selected K = 3

Why do we select K = 3?

Because around K = 3, the curve starts bending and becomes comparatively flatter. This is called the elbow point.

What is inertia?

Inertia is the sum of squared distances between each data point and its nearest cluster centroid.

Viva questions:

Q. Why do we use the Elbow Method?

Ans. To find the optimal number of clusters.

Q. What is inertia?

Ans. It measures how closely data points are grouped around their centroids.

Q. What happens when K increases?

Ans. Inertia generally decreases.

Q. What is the elbow point?

Ans. It is the point where the decrease in inertia starts slowing down.

## 4. Most important viva questions and answers

Q1. What is Machine Learning?

Machine Learning is a branch of AI that allows computers to learn from data and make predictions or decisions.

Q2. What is clustering?

Clustering is an unsupervised learning technique that groups similar data points together.

Q3. What is K-Means clustering?

K-Means is an unsupervised machine learning algorithm that divides data into K clusters based on similarity.

Q4. Is K-Means supervised or unsupervised?

Unsupervised learning.

Q5. Why is it called K-Means?

Because it divides data into K clusters and calculates the mean (centroid) of each cluster.

Q6. What is a centroid?

A centroid is the center point of a cluster, calculated using the mean of its data points.

Q7. What is K in K-Means?

K represents the number of clusters.

Q8. What is the Elbow Method?

It is a technique used to find the optimal number of clusters by plotting inertia against the number of clusters.

Q9. What is inertia?

Inertia is the sum of squared distances between data points and their nearest cluster centroid.

Q10. What is `random_state=42`?

It ensures reproducible results by controlling random initialization.

Q11. What is `fit()`?

It trains the K-Means model on the given dataset.

Q12. What is `fit_predict()`?

It trains the model and returns the cluster labels for each data point.

Q13. What is `k-means++`?

It is an initialization technique that selects better initial centroids to improve clustering.

Q14. What is `df.shape`?

It returns the number of rows and columns. Here, the output is `(2823, 2)`.

Q15. What is the difference between classification and clustering?

- Classification: Supervised learning.
- Clustering: Unsupervised learning.

## 6. Advantages and disadvantages

Advantages

1. Simple and easy to implement.
2. Fast for large datasets.
3. Easy to understand.
4. Useful for grouping similar data.

Disadvantages

1. K must be selected beforehand.
2. Sensitive to outliers.
3. Results depend on initial centroids.
4. Not suitable for every type of cluster shape.
