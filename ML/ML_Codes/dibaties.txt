## 8. StandardScaler

Your code:

```
scaler = StandardScaler()X_train = scaler.fit_transform(X_train)X_test = scaler.transform(X_test)
```

Explanation:

StandardScaler converts features into a common scale.

It uses the formula:

\\[ z = \frac{x-\mu}{\sigma} \\]

Where:

- x = Original value
- μ = Mean
- σ = Standard deviation

Viva questions

Q1. Why do we use StandardScaler?

A: To bring features to a comparable scale.

Q2. Why is scaling important in KNN?

A: Because KNN uses distance calculations. Features with larger numerical ranges can dominate the distance.

Q3. Difference between fit and transform?

A:

- Fit calculates the mean and standard deviation.
- Transform applies scaling using those values.

Definition:

KNN is a supervised machine learning algorithm used for classification and regression.

How does KNN work?

1. Select the value of K.
2. Calculate distances between data points.
3. Find the K nearest neighbors.
4. Check their classes.
5. Predict the majority class.

Viva questions

Q1. What is KNN?

A: KNN stands for K-Nearest Neighbors. It predicts the class based on the nearest data points.

Q2. Is KNN supervised or unsupervised?

A: Supervised learning.

Q3. What is K in KNN?

A: K represents the number of nearest neighbors considered for prediction.

Q4. What happens if K is too small?

A: The model may become sensitive to noise and overfit.

Q5. What happens if K is too large?

A: The model may underfit.

Q6. What is Euclidean distance?

A: It measures the straight-line distance between two points.

\\[ d=\sqrt{\sum\_{i=1}^{n}(x_i-y_i)^2} \\]

Q7. What is Manhattan distance?

A: It calculates the sum of absolute differences between coordinates.
