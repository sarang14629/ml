To implement the Gradient Descent algorithm in Python and find the local minimum of a given mathematical function using its derivative.

## 2. What is Gradient Descent?

Gradient Descent is an optimization algorithm used to minimize a function by repeatedly updating its input value in the direction opposite to the gradient.

Simple explanation: It finds the lowest point of a curve step by step.

## 3. Important concepts

| Term          | Meaning                              |
| ------------- | ------------------------------------ |
| Gradient      | Derivative of a function             |
| Learning rate | Controls the size of each step       |
| Iteration     | One repetition of the algorithm      |
| Local minimum | Lowest point in a nearby region      |
| Tolerance     | Minimum acceptable change            |
| Optimization  | Finding the minimum or maximum value |

- `function`: Mathematical function.

Step 4: Calculate derivative

```
gradient = lambdify(x, function.diff(x))
```

Calculates the derivative of the function and converts it into a numerical function.

Step 5: Update the value

```
start = start - learn_rate * gradient(prev_x)
```

This is the main Gradient Descent formula:

\\[ x\_{new}=x\_{old}-\alpha f'(x) \\]

Where:

- \\(x\\) = Current value
- \\(\alpha\\) = Learning rate
- \\(f'(x)\\) = Derivative

Step 6: Stopping condition

```
while step_size > tolerance and iters < n_iter:
```

The loop stops when the change becomes smaller than tolerance or maximum iterations are reached.

## 6. Important viva questions and answers

Q1. What is Gradient Descent?

It is an optimization algorithm used to minimize a function.

Q2. Why do we use Gradient Descent?

To find the minimum error or loss in Machine Learning models.

Q3. What is a learning rate?

It controls how big a step the algorithm takes during each update.

Q4. What happens if the learning rate is too high?

The algorithm may overshoot the minimum and fail to converge.

Q5. What happens if the learning rate is too small?

The algorithm takes more time to reach the minimum.

Q6. What is a derivative?

A derivative measures the rate of change of a function.

Q7. What is a local minimum?

A point where the function has a lower value than nearby points.

Q8. What is the role of NumPy?

It performs numerical calculations and creates arrays.

Q9. What is the role of Matplotlib?

It is used to visualize the function and its optimization steps.

Q10. What is SymPy?

It is a Python library used for symbolic mathematics.

Q11. What is lambdify?

It converts a symbolic mathematical expression into a numerical Python function.

Q12. What is tolerance?

It is the acceptable minimum change used to stop iterations.

Q13. What is an iteration?

One complete execution of the update process.

Q14. What is the formula for Gradient Descent?
